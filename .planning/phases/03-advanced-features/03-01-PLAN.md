<task id="1" type="code" priority="must-have">
  <title>Create config.js module with file-based persistence</title>
  <detail>
Create `config.js` that manages app settings:

```javascript
// Default config
const defaults = {
  interval: 30,           // seconds
  displayMode: 'cover',   // 'cover' | 'contain' | 'dual'
  onThisDay: false,       // boolean
  portraitPairs: false,    // boolean
};
```

- `loadConfig()` reads from `config.json`, merges with defaults for any missing keys
- `saveConfig(updates)` merges updates into current config and writes to disk
- `getConfig()` returns current in-memory config
- Export all three functions
  </detail>
