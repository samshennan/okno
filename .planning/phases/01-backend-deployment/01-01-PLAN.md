<task type="auto">
  <name>Implement OAuth 2.0 authentication with token persistence</name>
  <files>auth.js, tokens.json</files>
  <action>
Create auth.js implementing the OAuth flow from research Pattern "OAuth 2.0 Login Flow":

1. Import OAuth2Client from google-auth-library, express Router, fs, crypto, winston logger
2. Define SCOPES array: ['https://www.googleapis.com/auth/photospicker.mediaitems.readonly']
3. Create OAuth2Client with:
   - clientId: process.env.GOOGLE_CLIENT_ID
   - clientSecret: process.env.GOOGLE_CLIENT_SECRET
   - redirectUri: Will be set dynamically in /auth/login based on req.protocol and req.get('host')
     (supports both local dev and production HTTPS per context)
4. Implement loadTokens() function:
   - Try to read tokens.json
   - If exists, parse JSON and call oAuth2Client.setCredentials(tokens)
   - Return true if loaded, false if not found
   - Call on module load
5. Implement saveTokens(tokens) function:
   - If tokens.refresh_token exists, merge it (refresh token only sent once per research pitfall #2)
   - Write to tokens.json with JSON.stringify(tokens, null, 2)
   - Log "Tokens saved to disk"
6. Set up token refresh listener:
   - oAuth2Client.on('tokens', saveTokens)
7. GET /auth/login route:
   - Set redirectUri on oAuth2Client to `${req.protocol}://${req.get('host')}/auth/callback`
   - Generate random state with crypto.randomBytes(32).toString('hex')
   - Store state in req.session.oauthState
   - Generate auth URL with generateAuthUrl({ access_type: 'offline', scope: SCOPES, state, prompt: 'consent' })
   - Redirect to auth URL
8. GET /auth/callback route:
   - Check state matches req.session.oauthState (CSRF protection)
   - Call oAuth2Client.getToken(req.query.code)
   - Call oAuth2Client.setCredentials(tokens)
   - Call saveTokens(tokens)
   - Set req.session.authenticated = true
   - Redirect to /
9. GET /auth/status route:
   - Return JSON { authenticated: !!req.session.authenticated, hasTokens: !!oAuth2Client.credentials.access_token }
10. Export router and oAuth2Client (needed by picker.js and photo-proxy.js)

Follow the exact research example for token merging to avoid pitfall #2 (losing refresh token).
  </action>
  <verify>
Start server with `node server.js`. Visit http://localhost:3100/auth/status - should return authenticated: false. Visit /auth/login - should redirect to Google (will fail without real credentials, but route should exist). Check that auth.js exports router and oAuth2Client.
  </verify>
  <done>
