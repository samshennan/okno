<decisions_made>

- Per-user OAuth2Client cache (Map<userId, OAuth2Client>) instead of singleton -- avoids token refresh race conditions
- req.originalUrl in requireAuth (not req.path which is relative to mount point)
- express.static with index:false -- explicit auth-gated routes for HTML pages take precedence
- Transient OAuth2Client for /auth/login and /auth/callback (user identity unknown at that point)
- Lazy require('./auth') inside photo-cache.js refreshBaseUrls -- breaks circular dependency
- config.js uses all positional ? params (better-sqlite3 doesn't support mixed positional/named)
- VPS: switched git remote from HTTPS to SSH (git@github.com:samshennan/okno.git)
- VPS: app now runs under sam's PM2 (not root's PM2) -- root PM2 daemon stopped
- VPS: .env.production symlinked as .env (dotenv loads .env by default; 1Password service account was deleted so op run can't be used)
