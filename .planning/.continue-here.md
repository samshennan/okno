### 🚨 Critical Research Finding

**Google Photos Library API was deprecated March 31, 2025.** The `photoslibrary.readonly` scope in the original PRD is GONE. Must use **Picker API** (`photospicker.mediaitems.readonly`) instead, which requires users to manually select photos via Google's UI (not automatic background library fetch). This fundamentally changes the architecture.

### Key Decisions to Reflect

- Chrome as primary target (not Safari) - simplifies Wake Lock
- Picker API (not Library API) - research confirmed deprecation
- User must select photos explicitly - can't auto-browse library
- NoSleep.js primary strategy (not fallback) - Wake Lock broken on Safari 16.x
- File-based persistence sufficient - no database needed
