Rewrite auth.js to transform from single-user singleton to multi-user per-request auth. Keep the same router structure but make these specific changes:

**1. OAuth scopes -- add openid email profile explicitly:**
```javascript
const SCOPES = [
  'openid',
  'email',
  'profile',
  'https://www.googleapis.com/auth/photospicker.mediaitems.readonly'

```
The callback already calls the userinfo endpoint, and prompt:'consent' ensures re-consent. Adding these scopes makes the contract explicit.

**2. Remove the global singleton oAuth2Client** (lines 27-30). Replace with a per-user OAuth2Client cache:
```javascript
const clientCache = new Map(); // Map<userId, OAuth2Client>

function getOAuth2ClientForUser(userId) {
  if (clientCache.has(userId)) return clientCache.get(userId);
  const client = new OAuth2Client(
    process.env.GOOGLE_CLIENT_ID,
    process.env.GOOGLE_CLIENT_SECRET
  );
  // Load tokens from DB
  const { stmtSelectTokens } = getTokenStatements();
  const row = stmtSelectTokens.get(userId);
  if (row) {
    client.setCredentials({
      access_token: row.access_token,
      refresh_token: row.refresh_token,
      expiry_date: row.expiry_date,
      scope: row.scope,
      token_type: row.token_type
    });
  }
  // Listen for token refresh events -- save per-user
  client.on('tokens', (tokens) => {
    logger.info('Token refresh event received', { userId });
    saveTokens(userId, tokens);
  });
  clientCache.set(userId, client);
  return client;
}
```

**3. Update prepared statements to accept userId parameter:**
- `stmtSelectTokens`: `db.prepare('SELECT * FROM tokens WHERE user_id = ?')`
- `stmtUpsertTokens`: Change `VALUES (1, ...)` to `VALUES (?, ...)` -- accept userId as first bind parameter

Also add user-related prepared statements:
- `stmtUpsertUser`: `INSERT INTO users (email, display_name, last_login) VALUES (?, ?, datetime('now')) ON CONFLICT(email) DO UPDATE SET display_name = excluded.display_name, last_login = datetime('now') RETURNING id`
  - Note: SQLite's RETURNING clause works with better-sqlite3. Use `.get()` to get the returned row.
- `stmtSelectUserByEmail`: `SELECT id FROM users WHERE email = ?`

**4. Update saveTokens to accept userId:**
```javascript
function saveTokens(userId, tokens) { ... }
```
The stmtUpsertTokens bind should use userId as the first parameter instead of hardcoded 1.

**5. Remove loadTokens() function and its startup call** (lines 55-105). No more loading tokens at module scope. Tokens are loaded on-demand via getOAuth2ClientForUser.

**6. Remove the global token refresh listener** (lines 94-97). Token refresh is now per-client inside getOAuth2ClientForUser.

**7. Rewrite /auth/callback handler:**
The callback must:
a. Exchange code for tokens (keep existing)
b. Call userinfo endpoint to get email + display_name (keep existing fetch to googleapis.com/oauth2/v2/userinfo)
c. Check ALLOWED_EMAILS -- if set and email not in list, redirect to `/login?error=not_authorised` instead of sending raw text response
d. UPSERT user: `stmtUpsertUser.get(email, displayName)` -- returns `{ id: N }`
e. Save tokens for that user_id: `saveTokens(userId, tokens)`
f. Create OAuth2Client for user: `getOAuth2ClientForUser(userId)` and set credentials
g. Set `req.session.userId = userId` (replace `req.session.authenticated = true`)
h. Redirect to `/`

The OAuth flow still needs a temporary OAuth2Client for the token exchange (before we know the user). Create a transient client:
```javascript
const tempClient = new OAuth2Client(
  process.env.GOOGLE_CLIENT_ID,
  process.env.GOOGLE_CLIENT_SECRET
);
tempClient.redirectUri = `${req.protocol}://${req.get('host')}/auth/callback`;
const { tokens } = await tempClient.getToken(req.query.code);
```

**8. Rewrite /auth/login handler:**
Use a transient OAuth2Client for URL generation (not the per-user one, since we don't know who is logging in yet). Same pattern as current code but with a new `OAuth2Client` instance.

**9. Rewrite /auth/status handler:**
Resolve userId from `req.session.userId`. If no userId, return `{ authenticated: false }`. If userId exists, get their OAuth2Client and return status from it.

**10. Rewrite /auth/logout handler:**
After destroying session, also remove the user's OAuth2Client from clientCache if possible (session is destroyed so we lose userId -- just destroy session and redirect). Change response from JSON to `res.redirect('/login')`.

**11. Add requireAuth middleware:**
```javascript
function requireAuth(req, res, next) {
  if (!req.session?.userId) {
    if (req.path.startsWith('/api/')) {
      return res.status(401).json({ error: 'authentication_required' });
    }
    return res.redirect('/login');
  }
  next();
}
```
Export this alongside the router and getOAuth2ClientForUser.

**12. Update module.exports:**

```javascript
module.exports = router;
module.exports.getOAuth2ClientForUser = getOAuth2ClientForUser;
module.exports.requireAuth = requireAuth;
```
Remove the old `module.exports.oAuth2Client = oAuth2Client` export.
