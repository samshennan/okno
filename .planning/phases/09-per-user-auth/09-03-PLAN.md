The current index.html is the landing/setup page. It already has auth status checking logic (fetches /auth/status and shows different UI based on auth state). Update this:

```html

  </div>
</div>
```

2. **Style the overlay** to match the Okno aesthetic:

3. **Add reconnect logic to the photo fetch error handler:**

- Neumorphic style consistent with other settings UI
- Icon from Lucide (already loaded on the page)
- Adequate spacing from other settings controls

**2. Wire logout button:**
```javascript
document.getElementById('logout-btn').addEventListener('click', async () => {
  try {
    const response = await fetch('/auth/logout', { method: 'POST' });
    // Regardless of response, redirect to login
    window.location.href = '/login';
  } catch (error) {
    // Even on network error, try to redirect
    window.location.href = '/login';
  }
});
```

**3. Add 401 handling to all API calls on the settings page:**

The settings page fetches /api/config (GET and POST). Find these fetch calls and add 401 handling:

```javascript
// After every fetch to /api/config or /auth/status:
if (response.status === 401) {
  window.location.href = '/login';
  return;
}
```

This ensures that if a user's session expires while they have settings open, they get redirected to login rather than seeing mysterious errors.

**4. Update the auth status check (if present):**

- Fetch /auth/status

- This is a safety net (server-side requireAuth already handles it)
