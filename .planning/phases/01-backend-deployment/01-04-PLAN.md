<task type="auto">
  <name>Create nginx config and deploy to VPS</name>
  <files>/etc/nginx/sites-available/okno (on VPS)</files>
  <action>
SSH into the VPS and configure nginx + SSL:

1. Create nginx config file `/etc/nginx/sites-available/okno` using research "Nginx Reverse Proxy Configuration":

```nginx
# Initial HTTP config for Let's Encrypt verification
server {
    listen 80;
    server_name okno.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:3100;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        proxy_read_timeout 60s;
        proxy_send_timeout 60s;
    }
}
```

2. Symlink to sites-enabled:
   ```bash
   sudo ln -s /etc/nginx/sites-available/okno /etc/nginx/sites-enabled/
   ```

3. Test and reload nginx:
   ```bash
   sudo nginx -t
   sudo systemctl reload nginx
   ```

4. Install certbot if not already installed:
   ```bash
   sudo apt update
   sudo apt install -y certbot python3-certbot-nginx
   ```

5. Obtain SSL certificate (certbot will auto-update nginx config to add HTTPS):
   ```bash
   sudo certbot --nginx -d okno.yourdomain.com
   ```
   Follow prompts: enter email, agree to TOS, choose redirect HTTP to HTTPS (option 2).

6. Verify auto-renewal is configured:
   ```bash
   sudo systemctl status certbot.timer
   ```

7. Upload Okno code to VPS:
   - Clone git repo to VPS (or rsync code)
   - Install dependencies: `npm install --production`
   - Ensure OP_SERVICE_ACCOUNT_TOKEN is set in VPS environment (add to ~/.bashrc or /etc/environment)

8. Start app via PM2 + 1Password:
   ```bash
   ./start.sh
   ```

9. Save PM2 process list and enable startup script:
   ```bash
   pm2 save
   pm2 startup
   ```
   Run the command PM2 outputs (creates systemd service).

After deployment:

- Check nginx logs: `sudo tail -f /var/log/nginx/access.log` - requests should proxy to :3100

This implements requirements INFRA-01 (nginx + SSL) and INFRA-02 (PM2 auto-restart + reboot survival).
