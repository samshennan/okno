**Step 1: Create optimization script**

Create `scripts/optimize-demo-photos.js` that:
1. Reads JPEG/PNG files from a `demo-originals/` directory (at project root)
2. Resizes each to 2048px on longest edge using sharp (existing devDependency)
3. Outputs as JPEG at quality 80 with mozjpeg compression
4. Strips unnecessary metadata
5. Writes optimized files as `photo-01.jpg` through `photo-NN.jpg` in `public/demo/`
6. Generates `public/demo/manifest.json` with metadata for each photo

Manifest format:
```json
[
  {
    "id": "demo-01",
    "file": "photo-01.jpg",
    "createTime": "2019-03-15T14:30:00Z",
    "width": 4032,
    "height": 3024,
    "description": "Beach sunset"
  }
]
```

**Create demo-photos.js:**

An Express router module with two endpoints, completely isolated from auth/cache/photo-proxy:

```javascript
// demo-photos.js -- serves random demo photos from public/demo/
// ISOLATION: This module must NEVER import auth.js, photo-cache.js, or photo-proxy.js
const express = require('express');
const router = express.Router();
const path = require('path');
const fs = require('fs');

const DEMO_DIR = path.join(__dirname, 'public', 'demo');
let manifest = [];

// Load manifest on module init
try {
  manifest = JSON.parse(fs.readFileSync(path.join(DEMO_DIR, 'manifest.json'), 'utf8'));
  console.log(`Demo photos loaded: ${manifest.length} photos`);
} catch (e) {
  console.warn('Demo manifest not found:', e.message);
}

// GET /api/demo/random -- serve a random demo photo
router.get('/random', (req, res) => { ... });

// GET /api/demo/health -- demo status
router.get('/health', (req, res) => { ... });
```

**GET /api/demo/random:**
1. If manifest is empty, return 503 `{ error: 'No demo photos available' }`
2. Pick a random photo from manifest
3. Verify file exists on disk; if not, return 404
4. Set response headers matching the real photo proxy format:
   - `Content-Type: image/jpeg`
   - `Cache-Control: public, max-age=3600` (demo photos can be cached aggressively)
   - `X-Photo-Id: {item.id}`
   - `X-Photo-CreateTime: {item.createTime}`
   - `X-Photo-IsPortrait: {true/false}` based on height > width
5. Use `res.sendFile(filePath)` to serve the photo

**GET /api/demo/health:**
1. Return JSON matching the structure the slideshow init expects:
```json
{
  "status": "ok",
  "demoMode": true,
  "cache": {
    "totalItems": 12,
    "portraitCount": 4
  }
}
```

**Mount in server.js:**

Add these lines after the existing route mounts (after the config routes, before the server start):

```javascript
// Mount demo routes (fully isolated from auth/cache)
const demoRouter = require('./demo-photos');
app.use('/api/demo', demoRouter);

// Serve demo.html at /demo route
app.get('/demo', (req, res) => {
  res.sendFile(path.join(__dirname, 'public', 'demo.html'));
});

logger.info('Demo routes mounted');
```

**Critical isolation rules for demo-photos.js:**
- NO `require('./auth')`, `require('./photo-cache')`, `require('./photo-proxy')`, or `require('./config')`
- NO reference to `tokens.json`, `cache.json`, `config.json`
- NO `req.session` checks
- ONLY reads from `public/demo/` directory
