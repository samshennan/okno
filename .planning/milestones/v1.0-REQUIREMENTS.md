## v1 Requirements

### Authentication & Photo Access (AUTH)

- [x] **AUTH-01**: User can authenticate with Google Photos via OAuth 2.0 (authorization code flow) and tokens persist across server restarts in `tokens.json`
- [x] **AUTH-02**: User can select photos via Google Picker UI (Picker API with `photospicker.mediaitems.readonly` scope) and selected photos appear in slideshow
- [x] **AUTH-03**: Backend caches selected media item IDs + metadata (creationTime, width, height) in `cache.json` for random selection and filtering
- [x] **AUTH-04**: Backend automatically refreshes baseUrls every 50 minutes (before 60-min expiry) to prevent broken images

### Slideshow Display (DISP)

- [x] **DISP-01**: iPad displays fullscreen slideshow with black background, photos in cover-fit mode, no browser chrome visible
- [x] **DISP-02**: Photos crossfade smoothly between transitions (1-2s CSS opacity animation, no jarring swaps)
- [x] **DISP-03**: Next photo preloads while current photo displays (seamless transitions, no white flash or loading delay)
- [x] **DISP-04**: Slideshow interval is configurable via URL parameter (`?interval=30` for 30 seconds between photos)
- [x] **DISP-05**: Backend serves random photos from cache each interval (serendipitous rediscovery of memories)
- [x] **DISP-06**: Frontend uses two-image A/B swap pattern (alternating `<img>` elements) to prevent JavaScript memory leaks in long-running slideshow

### PWA + Screen Wake (PWA)

- [x] **PWA-01**: Screen stays awake indefinitely using NoSleep.js as primary strategy (Wake Lock API broken on iOS 16.x PWAs per WebKit bug #254545)
- [x] **PWA-02**: App works as fullscreen PWA (PWA manifest + Apple meta tags for Add to Home Screen, no Safari chrome)
- [x] **PWA-03**: App works in iOS Guided Access mode (kiosk mode for always-on display, no navigation away from page)

### Infrastructure & Deployment (INFRA)

- [x] **INFRA-01**: Backend runs on VPS with nginx reverse proxy and Let's Encrypt SSL (HTTPS required for OAuth callbacks)
- [x] **INFRA-02**: Backend runs via PM2 with auto-restart on crash and startup script on reboot
- [x] **INFRA-03**: Frontend auto-retries on fetch failures, backend uses exponential backoff on API calls (error resilience for network blips)
- [x] **INFRA-04**: Health check endpoint (`/api/health`) reports token status, cache size, last API call timestamp, uptime

### Advanced Features (ADV)

- [x] **ADV-01**: "On This Day" mode filters photos to only those taken on today's month+day across all years (mimics Google Photos Memories, unique differentiator)
- [x] **ADV-02**: Portrait pair mode detects two consecutive portrait photos and displays them side-by-side in landscape orientation (matches Aura's $200+ flagship feature)
- [x] **ADV-03**: Settings page (`/settings`) provides web UI to configure slideshow interval, enable/disable filters and modes, no code changes needed
