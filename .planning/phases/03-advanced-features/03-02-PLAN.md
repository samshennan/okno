<task id="1" type="code" priority="must-have">
  <title>Add On This Day filter to photo-cache.js</title>
  <detail>
Add a new function `getRandomOnThisDayItem()` to photo-cache.js:

1. Get today's month (0-11) and day (1-31) from server's local time
2. Filter `cache.mediaItems` where `createTime` matches today's month+day
3. Parse `createTime` (ISO 8601 string) with `new Date(item.createTime)`
4. Return random item from filtered set, or `null` if no matches

Also add `getOnThisDayCount()` to return how many photos match today's date (useful for UI feedback).

Export both new functions.
  </detail>
  <files>photo-cache.js</files>
</task>

<task id="2" type="code" priority="must-have" depends="1">
  <title>Add On This Day query parameter to photo-proxy.js</title>
  <detail>
Modify `GET /api/photo/random` to accept `?onThisDay=true` query parameter:

1. If `onThisDay=true`, call `photoCache.getRandomOnThisDayItem()` instead of `getRandomItem()`
2. If no photos match today's date, return 404 with `{ error: 'no_photos_today', message: 'No photos from this day in history', count: 0 }`
3. Add `X-Photo-OnThisDay: true` response header when serving an On This Day photo
4. Add `X-Photo-OnThisDayCount: N` header with total matching photos count
  </detail>
  <files>photo-proxy.js</files>
</task>
