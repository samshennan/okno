<decisions>
## Implementation Decisions

### Hero visual
- Both animated GIF + static mockup image of Okno running on an iPad on a shelf
- Use a device mockup tool (e.g., Shots.so, Mockuphone) to place screenshots into iPad frame
- Show demo mode photos in the slideshow (no real/private photos)
- Layout: one-liner tagline first, then hero visual below it

### README structure & tone
- Primary audience: interviewers and recruiters (not OSS developers)
- Storytelling/narrative tone — personal, shows why it was built and the problem it solves
- Compact length — everything within ~1 scroll, punchy and scannable
- Minimal setup section — brief clone/install/env-vars, not a tutorial. Live demo link is primary CTA

### Product decisions section
- 3-4 best decisions from PROJECT.md decision log
- Claude selects which decisions best demonstrate product leadership thinking
- Framing format: Claude's discretion (tradeoff pairs vs narrative)

### Claude's Discretion
- Architecture diagram level of detail and Mermaid style
- Which 3-4 product decisions to feature from the decision log
- Whether to frame decisions as tradeoff pairs or narrative paragraphs
- Whether tech stack gets its own section or folds into decisions
- GIF recording approach and length
- Exact README section ordering beyond hero → features → decisions → setup

</decisions>
