# OKNO UI Moodboard

## Design References for Future UI Pass

### Key Aesthetic Principles Observed

**1. Sunken/Inset Input Fields**
- Subtle inner shadows creating depth
- Light backgrounds with barely-there borders
- Icon integration within fields
- Generous padding and breathing room

**2. Neumorphism/Soft UI Elements**
- Soft shadows (both inner and outer)
- Subtle elevation changes
- Light color palettes with low contrast
- Rounded corners (10-20px radius)

**3. Card-Based Layouts**
- Grouped information in clean containers
- Frosted glass/backdrop blur effects
- Strategic use of white space
- Clear visual hierarchy

**4. Typography**
- San Francisco/System fonts
- Careful letter spacing
- Mix of weights (300-600)
- Generous line height (1.5-1.8)

**5. Color Philosophy**
- Muted, calm palettes
- Eucalyptus greens, warm neutrals
- Low saturation
- Soft shadows over hard lines

**6. Button Design**
- Pill-shaped with subtle shadows
- State changes via elevation, not color alone
- Grouped in containers with shared backgrounds
- Icon + text combinations

**7. Modern iOS/Material Influence**
- Backdrop filters and blur
- Smooth cubic-bezier animations
- Touch-friendly hit areas
- Progressive disclosure
