## Decisions Made

### Design Decisions

1. **Neumorphic over gradient backgrounds**
   - Rationale: More cohesive 3D depth, matches moodboard references
   - Result: Unified #F0F0F3 background creates better shadow definition

2. **Dual shadow system**
   - Formula: `-Npx -Npx #FFFFFF, Npx Npx rgba(174,174,192,0.4)`
   - Light source: Top-left
   - Consistent across all raised elements

3. **Sunken inputs without borders**
   - Inspired by PIAP Space website reference
   - Creates carved-in appearance
   - More premium feel than bordered inputs

### Architecture Decisions (For Tomorrow)

4. **Storage Model: Hybrid Approach**
   - Default: Client-side localStorage (zero GDPR risk)
   - Optional: VPS sync with explicit consent
   - Rationale: Start simple, add complexity only if users request it

5. **Font Recommendation: Inter Variable**
   - Modern, professional, free
   - Variable font (one file, all weights)
   - Used by GitHub, Mozilla
   - Better than system fonts

6. **Icon Set: Lucide**
   - MIT license, clean style
   - Matches neumorphic aesthetic
   - Replace emojis (🪟 🐛 ✨ 💝 📎)
