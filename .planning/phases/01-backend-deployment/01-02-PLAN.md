Create picker.js implementing the Picker session flow from research Pattern "Picker API Session Flow":

2. Create Express router
3. POST /api/picker/start route:
   - Get access token: `const { token } = await oAuth2Client.getAccessToken()`
   - Call Picker API to create session:
     ```javascript
     const response = await fetch('https://photospicker.googleapis.com/v1/sessions', {
       method: 'POST',
       headers: { 'Authorization': `Bearer ${token}` }
     });
     const session = await response.json();
     ```
   - Store session.id in req.session.pickerSessionId
   - Return JSON with:
     - sessionId: session.id
     - pickerUrl: session.pickerUri + '/autoclose' (auto-close tab per research)
     - pollInterval: session.pollingConfig.pollInterval
     - timeout: session.pollingConfig.timeoutIn
   - Log session creation
4. GET /api/picker/status/:sessionId route:
   - Get access token
   - Fetch session status: GET https://photospicker.googleapis.com/v1/sessions/:sessionId with auth header
   - Parse response, return { done: session.mediaItemsSet === true }
   - If not done, return { done: false }
5. POST /api/picker/complete/:sessionId route:
   - Get access token
   - Paginate through mediaItems.list with sessionId query param (pageSize: 100 max per research):
     ```javascript
     let allItems = [];
     let pageToken = null;
     do {
       const url = new URL('https://photospicker.googleapis.com/v1/mediaItems');
       url.searchParams.set('sessionId', req.params.sessionId);
       url.searchParams.set('pageSize', '100');
       if (pageToken) url.searchParams.set('pageToken', pageToken);
       const response = await fetch(url, {
         headers: { 'Authorization': `Bearer ${token}` }
       });
       const data = await response.json();
       allItems.push(...(data.mediaItems || []));
       pageToken = data.nextPageToken;
     } while (pageToken);
     ```
   - Call photoCache.setItems(allItems, req.params.sessionId) to cache
   - Return { count: allItems.length }
   - Log count of items cached
6. Export router

<task type="auto">
  <name>Implement photo cache with baseUrl refresh</name>
  <files>photo-cache.js, cache.json</files>
  <action>
Create photo-cache.js managing in-memory cache with persistence and baseUrl refresh:

1. Import fs, oAuth2Client from auth.js, winston logger
2. Define CACHE_PATH = './cache.json'
3. Define REFRESH_INTERVAL_MS = 50 * 60 * 1000 (50 minutes per research Pattern "BaseUrl Refresh Strategy")
4. Create in-memory state:
   ```javascript
   let cache = {
     sessionId: null,
     mediaItems: [],    // Array of PickedMediaItem objects with { id, baseUrl, mimeType, createTime, ... }
     lastRefresh: null,
     lastApiCall: null
   };
   ```
5. Implement loadCache():
   - Try to read cache.json
   - If exists, parse and assign to cache object
   - Log "Loaded {count} items from cache"
   - Return true/false
   - Call on module load
6. Implement saveCache():
   - Write cache to cache.json with JSON.stringify(cache, null, 2)
   - Log "Cache saved to disk"
7. Implement setItems(items, sessionId):
   - Set cache.mediaItems = items
   - Set cache.sessionId = sessionId
   - Set cache.lastRefresh = new Date().toISOString()
   - Call saveCache()
   - Start baseUrl refresh interval if not already running
8. Implement getItem(id):
   - Find item in cache.mediaItems where item.id === id
   - Return item or null
9. Implement getRandomItem():
   - If cache.mediaItems.length === 0, return null
   - Pick random index: Math.floor(Math.random() * cache.mediaItems.length)
   - Return cache.mediaItems[index]
10. Implement size():
    - Return cache.mediaItems.length
11. Implement getSessionId(), getLastRefresh(), getLastApiCall() getters
12. Implement async refreshBaseUrls():
    - If !cache.sessionId or mediaItems.length === 0, return
    - Get access token
    - Re-call mediaItems.list with cache.sessionId to get fresh baseUrls (per research Pattern):
      ```javascript
      let allItems = [];
      let pageToken = null;
      do {
        const url = new URL('https://photospicker.googleapis.com/v1/mediaItems');
        url.searchParams.set('sessionId', cache.sessionId);
        url.searchParams.set('pageSize', '100');
        if (pageToken) url.searchParams.set('pageToken', pageToken);
        const response = await fetch(url, {
          headers: { 'Authorization': `Bearer ${(await oAuth2Client.getAccessToken()).token}` }
        });
        const data = await response.json();
        allItems.push(...(data.mediaItems || []));
        pageToken = data.nextPageToken;
      } while (pageToken);
      ```
    - Update cache.mediaItems with fresh baseUrls (match by id)
    - Set cache.lastRefresh = new Date().toISOString()
    - Set cache.lastApiCall = new Date().toISOString()
    - Call saveCache()
    - Log "Refreshed {count} baseUrls"
13. Set up refresh interval:
    - `setInterval(refreshBaseUrls, REFRESH_INTERVAL_MS)` after first setItems() call
14. Export { getItem, getRandomItem, setItems, size, getSessionId, getLastRefresh, getLastApiCall }

Follow research guidance: store media item IDs persistently, baseUrls in memory, refresh before 60-min expiry.
