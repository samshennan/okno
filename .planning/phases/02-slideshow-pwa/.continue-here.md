## Context

### Mental Model
The Google Picker API v1 uses a polling-based flow:
1. Frontend calls `/api/picker/start` → creates picker session
2. Frontend opens `session.pickerUri` (with `/autoclose` appended)
3. User selects photos, clicks "Done" → picker window closes automatically
4. Frontend polls `/api/picker/status/:sessionId` checking `mediaItemsSet` flag
5. When flag is true → frontend calls `/api/picker/complete/:sessionId` to fetch photos
6. Backend fetches selected photos and caches them

**The Problem:** Step 4 never succeeds - `mediaItemsSet` stays false forever.
