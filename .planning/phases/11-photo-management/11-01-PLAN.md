Add migration v2 block after the existing `if (version < 1)` block:

```javascript
if (version < 2) {
  db.transaction(() => {
    db.exec('ALTER TABLE photo_cache ADD COLUMN hidden INTEGER DEFAULT 0');
    db.pragma('user_version = 2');
  })();
}
```

**photo-cache.js -- New prepared statements:**
Add to `getStatements()`:
- `hideItem`: `UPDATE photo_cache SET hidden = 1 WHERE user_id = ? AND media_item_id = ?`
- `unhideItem`: `UPDATE photo_cache SET hidden = 0 WHERE user_id = ? AND media_item_id = ?`
- `unhideAll`: `UPDATE photo_cache SET hidden = 0 WHERE user_id = ?`
- `selectHidden`: `SELECT media_item_id, media_item_data FROM photo_cache WHERE user_id = ? AND hidden = 1`
- `countHidden`: `SELECT COUNT(*) as count FROM photo_cache WHERE user_id = ? AND hidden = 1`

**Update `selectAll` statement** to include hidden column:
`SELECT media_item_id, media_item_data, session_id, hidden FROM photo_cache WHERE user_id = ?`

**Update `getUserCache`** -- when loading from DB, propagate hidden flag:
```javascript
cacheData.mediaItems = rows.map(row => {
  const item = JSON.parse(row.media_item_data);
  item.hidden = !!row.hidden;
  return item;
});
```

**Filter hidden items in selection functions:**
- `getRandomItem`: filter `cache.mediaItems.filter(item => !item.hidden)` before random selection
- `getOnThisDayItems`: add `.filter(item => !item.hidden)` to the existing filter chain
- `getPortraitItems`: add `.filter(item => !item.hidden)` to the existing filter chain

**Update `size()`** to return visible count only:
```javascript
function size(userId) {
  const cache = getUserCache(userId);
  return cache.mediaItems.filter(item => !item.hidden).length;
}
```

**Preserve hidden flag in `refreshBaseUrls`:**
When refreshBaseUrls replaces in-memory items with fresh data from the Google API, the fresh items will NOT have the `hidden` property. You MUST preserve the existing hidden flag during the merge. In the section where fresh items replace existing items in the cache array, merge the hidden flag from the existing item onto the fresh item:
```javascript
// When building the new items array from fresh Google data:
// For each fresh item, look up the existing item and preserve its hidden flag
freshItem.hidden = existingItem ? existingItem.hidden : false;
```
Without this, hidden photos would reappear within ~50 minutes when the next baseUrl refresh cycle replaces the in-memory cache items, stripping the hidden flag.

**Add new exported functions:**

`hideItem(userId, mediaItemId)` -- Updates DB (hideItem stmt), sets item.hidden=true in memory cache. Returns true if item found, false otherwise.

`unhideItem(userId, mediaItemId)` -- Updates DB (unhideItem stmt), sets item.hidden=false in memory cache. Returns true if item found, false otherwise.

`unhideAll(userId)` -- Updates DB (unhideAll stmt), sets all items.hidden=false in memory cache. Returns count of items unhidden.

`getHiddenItems(userId)` -- Queries DB with selectHidden stmt. Returns array of parsed media_item_data objects. (Uses DB query, not in-memory filter, to ensure consistency.)

`hiddenCount(userId)` -- Queries DB with countHidden stmt. Returns the count number.

**Add all new functions to module.exports.**

Do NOT remove hidden items from the in-memory cache array -- they need to stay for unhide functionality. Only filter them out in selection functions.

<task type="auto">
  <name>Task 2: API endpoints for hide/unhide/hidden-list/thumbnail</name>
  <files>photo-proxy.js</files>
  <action>
Add four new routes to photo-proxy.js (the router is mounted at `/api/photo` in server.js, so paths are relative):

**POST /hide/:mediaItemId**
- Calls `photoCache.hideItem(req.session.userId, req.params.mediaItemId)`
- Returns 200 `{ success: true }` if found
- Returns 404 `{ error: 'not_found' }` if item not in cache

**POST /unhide/:mediaItemId**
- Calls `photoCache.unhideItem(req.session.userId, req.params.mediaItemId)`
- Returns 200 `{ success: true }` if found
- Returns 404 `{ error: 'not_found' }` if item not in cache

**POST /unhide-all**
- Calls `photoCache.unhideAll(req.session.userId)`
- Returns 200 `{ success: true, count: N }` where N is items unhidden

**GET /hidden**
- Calls `photoCache.getHiddenItems(req.session.userId)`
- Returns 200 with JSON array of hidden items (each item is the parsed media_item_data)
- Include `count` field: `{ items: [...], count: N }`

**GET /thumbnail/:mediaItemId**
- Calls `photoCache.getItem(req.session.userId, req.params.mediaItemId)` to get the cached item
- If not found, return 404
- Extract baseUrl from `item.mediaFile?.baseUrl || item.baseUrl`
- Append `=w240-h240-c` for square crop thumbnail
- Fetch from Google with `Authorization: Bearer ${token}` (same pattern as /random)
- Proxy the image bytes back with appropriate Content-Type
- On Google fetch failure, return 502
- Log thumbnail requests at debug level (not info -- these will be frequent from the settings grid)

All endpoints use `req.session.userId` (already available via requireAuth middleware on the `/api/photo` mount).
